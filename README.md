# 📊 Supermarket Sales Analysis Using SQL

## 📌 Project Overview

This project demonstrates foundational SQL skills through a supermarket sales analysis using a small sample dataset of five transactions.

Using SQLite, I created a sales table, inserted sample records, and wrote SQL queries to explore sales performance across products and cities.

The analysis includes calculating revenue using price and quantity, aggregating sales by product and city, identifying the highest-revenue product, and finding the lowest-revenue city.

**SQL Skills Demonstrated:** CREATE TABLE, INSERT INTO, SELECT, WHERE, SUM, GROUP BY, ORDER BY and LIMIT.

**Project File:** `sales_analysis.sql`
